
# مولد قصص الأطفال بالذكاء الاصطناعي

تطبيق ينشئ قصصاً قصيرة بالعربي/الإنجليزي مع رسمة توضيحية وأسئلة فهم تفاعلية، بتصميم ملوّن مستوحى من ورقة العمل في الصورة.

## الميزات

1. **نموذج إنشاء القصة** في الصفحة الرئيسية:
   - الموضوع: قائمة جاهزة (الأمانة، الصدق، التعاون، حسن الخلق، سيرة شخصية…) + خانة كتابة موضوع مخصص
   - اللغة: عربي / English
   - الحجم: صغيرة (~60 كلمة) / متوسطة (~120 كلمة) / كبيرة (~220 كلمة)
   - الفئة العمرية: اختياري (مفردات أبسط)
   - زر **"إنشاء قصة"**

2. **عرض القصة** بتصميم يشبه ورقة العمل:
   - عنوان القصة بخط مرح
   - فقرة القصة داخل إطار أصفر منقّط (مثل الصورة)
   - رسمة كرتونية مولّدة بالذكاء الاصطناعي بجانب النص
   - 5 أسئلة فهم متنوعة: اختيار من متعدد + صح/خطأ + أكمل الفراغ
   - دوائر برتقالية للإجابات (يلوّنها/يضغط عليها الطفل)
   - زر **"تصحيح الإجابات"** يُظهر الصحيح بأخضر والخطأ بأحمر مع شرح
   - زر **"قصة جديدة"** و**"طباعة / تحميل PDF"**

3. **حفظ القصص**: قائمة "قصصي" تعرض القصص السابقة للمستخدم

4. **المصادقة**: تسجيل دخول بالبريد + كلمة المرور و Google

## الخطوات التقنية

1. تفعيل **Lovable Cloud** (مصادقة + قاعدة بيانات + تخزين الصور)
2. جدول `stories`: id, user_id, title, language, size, topic, story_text, image_url, questions (jsonb), created_at — مع RLS لكل مستخدم
3. صفحات/مسارات TanStack:
   - `/login` — تسجيل دخول/تسجيل
   - `/` — نموذج الإنشاء + قائمة قصصي
   - `/story/$id` — عرض القصة والأسئلة
4. **Server function** `generateStory` (محمية بـ requireSupabaseAuth):
   - تستدعي **Lovable AI Gateway** بنموذج `google/gemini-3-flash-preview` مع structured output (Zod) لإرجاع: `{title, story, questions:[{type, question, options?, correctAnswer, explanation}]}`
   - تستدعي نموذج توليد الصور `google/gemini-2.5-flash-image` لإنشاء رسمة كرتونية مناسبة لمحتوى القصة
   - تحفظ الصورة في Supabase Storage والقصة في الجدول
5. واجهة الأسئلة التفاعلية مع تصحيح فوري وعدّاد نتيجة
6. تصدير PDF عبر `react-to-print` أو `window.print()` مع CSS طباعة مخصص

## نظام التصميم

- خطوط مرحة: **Fredoka** (عربي/إنجليزي) للعناوين، **Cairo** للنص
- ألوان: أصفر دافئ `#F5B82E`, برتقالي `#F97316`, أزرق طفولي `#3B82F6`, خلفية كريمية `#FFFBEB`
- إطارات منقّطة، حواف مدوّرة كبيرة، ظلال ناعمة، رسوم متحركة لطيفة عند الإنشاء
- دعم RTL تلقائي عند اختيار العربية

## التفاصيل التقنية

```text
src/
  routes/
    index.tsx            (نموذج + قائمة قصصي)
    login.tsx
    story.$id.tsx
    api/                 (server routes إن لزم)
  lib/
    story.functions.ts   (generateStory, listStories)
  components/
    StoryForm.tsx
    StoryView.tsx
    QuestionItem.tsx
    PrintableStory.tsx
```

النموذج يُرجِع JSON منظّم بـ `Output.object` ليضمن التزام بنية الأسئلة. الصور تُولّد بنفس الـ gateway وتُرفع إلى bucket عام `story-images`.
